## Brand & Style

This design system embodies an authoritative, tech-forward B2B & B2C talent ecosystem where human intuition meets predictive machine intelligence. The aesthetic bridges high-performance enterprise SaaS utility with the vibrant responsiveness of next-generation artificial intelligence. 

The visual movement is **Corporate Modern infused with Precision Glass & Luminescent AI Accents**:
- Foundational layouts remain crisp, rational, and data-dense, inspiring uncompromising trust among enterprise talent leaders, recruiters, and executive decision-makers.
- Active AI interventions (match scores, algorithmic skill mappings, predictive sourcing, automated pipeline insights) are treated as luminous micro-events featuring violet-to-cyan spectrum glows, sharp edge highlights, and subtle translucency.
- The interface feels decisive, ultra-responsive, calm, and unmistakably ahead of traditional legacy HR platforms.

## Colors

The palette establishes a high-contrast hierarchy anchored by deep slate infrastructure, electric indigo execution, and ethereal AI accentuation.

### Semantic Color Assignments
- **Primary (`#4F46E5` / `#6366F1`)**: Used for dominant primary interactions, key actions, step progression, and active workspace toggles.
- **Secondary (`#8B5CF6`)**: Represents semantic AI intelligence, algorithmic reasoning, synthesis triggers, and smart automation indicators.
- **Tertiary / Accent (`#06B6D4`)**: Reserved for hyper-match indicators, realtime data streaming pings, candidate fit vectors, and positive predictive deltas.
- **Neutral Dark (`#0F172A`)**: Primary text, headings, dark canvas containers, enterprise sidebar headers, and heavy visual weights.
- **Surface & Canvas (`#FFFFFF`, `#F8FAFC`, `#F1F5F9`)**: Clean, clinical backdrop tiers ensuring optimum legibility for complex tabular candidate records.
- **Subtle Structural Borders (`#E2E8F0`, `#CBD5E1`)**: Crisp visual partitions with zero visual noise.

### AI Gradient Signatures
- **Predictive Gradient**: Linear 135deg from `#4F46E5` through `#8B5CF6` to `#06B6D4`. Used for candidate match meters, generative talent briefs, and premium AI triggers.
- **AI Surface Tint**: `#8B5CF6` at 4% to 8% opacity on white or slate backgrounds for generative suggestion blocks.

## Typography

Typography pairs the structural geometric dynamism of **Plus Jakarta Sans** for prominent headers, metric scores, and executive summaries with the precision, neutral clarity, and dense horizontal economy of **Inter** for data tables, form fields, and systemic UI labels.

- **Numerics & Scores**: All candidate scores, match percentages, and currency values must utilize tabular lining figures (`font-variant-numeric: tabular-nums`) to preserve column alignment across candidate comparison matrices.
- **Hierarchy Enforcement**: Keep body sizes compact (`14px` default) to maximize vertical information density without sacrificing readability or accessibility.

## Layout & Spacing

The layout is built upon an 8-point base grid utilizing a **hybrid fluid-restrained responsive framework**. Enterprise data density demands purposeful spacing to avoid visual fatigue during long recruitment workflows.

### Breakpoints & Grids
- **Desktop (≥1280px)**: 12-column responsive layout with 24px gutters and max-width clamping at 1600px for high-density monitors. Sidebars default to a fixed 280px docking rail.
- **Tablet (768px - 1279px)**: 8-column layout with 16px gutters, auto-collapsing sidebar into an iconified 68px command strip.
- **Mobile (<768px)**: 4-column layout with 16px margins, stackable card structures, horizontal swipe containers for candidate pipeline kanban stages, and sticky bottom utility bars.

### Data Densities
- **Standard Mode**: Row height 56px, ideal for candidate lists containing dual avatars, role titles, and score badges.
- **Compact Analysis Mode**: Row height 40px, tailored for batch resume processing, multi-variable filtering, and audit log inspection.

## Elevation & Depth

Depth is established via **clean architectural layering combined with tinted ambient backdrops** rather than muddy grey drop-shadows.

### Elevation Levels
- **Level 0 (Base Canvas)**: Flat `#F8FAFC`, zero elevation, framing operational workboards.
- **Level 1 (Cards & Data Panels)**: `#FFFFFF` surface accompanied by a crisp hairline border (`1px solid #E2E8F0`) and an ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.03)`.
- **Level 2 (Interactive Hover & Dropdowns)**: `#FFFFFF` elevated with `0 10px 15px -3px rgba(15, 23, 42, 0.08), 0 4px 6px -4px rgba(15, 23, 42, 0.03)` with border `#CBD5E1`.
- **Level 3 (Modals & Candidate Drawers)**: `#FFFFFF` floating surface paired with a dark slate dimming scrim (`rgba(15, 23, 42, 0.45)` with 4px backdrop-filter blur) and `0 20px 25px -5px rgba(15, 23, 42, 0.1), 0 8px 10px -6px rgba(15, 23, 42, 0.04)`.
- **AI Aura Elevation**: Generative summary bubbles and top candidate match cards inherit a dual outer glow: `0 0 0 1px rgba(139, 92, 246, 0.25), 0 8px 24px -4px rgba(99, 102, 241, 0.12)`.

## Shapes

The design system employs a **Level 2 (Rounded)** curvature standard, striking an equilibrium between modern approachable consumer tools and institutional software rigor.

- **Primary Cards & Modals**: `12px` to `16px` (`rounded-lg` to `rounded-xl`) corner radius creates friendly containment without looking overly playful.
- **Inputs & Data Controls**: `8px` (`rounded-md`) ensuring alignment with standard data table row constraints.
- **Tags, Match Pills & Badges**: Fully pill-shaped (`9999px`) to emphasize distinct modularity against orthogonal data grids.

## Components

### Buttons
- **Primary AI Action**: Linear gradient fill (135deg, `#4F46E5` to `#7C3AED`), white text, crisp 1px top highlight border (`rgba(255, 255, 255, 0.2)`), subtle hover glow `0 4px 14px 0 rgba(79, 70, 229, 0.38)`.
- **Secondary**: Crisp white background, `#0F172A` text, `1px solid #E2E8F0` border. Hover background `#F8FAFC`, border `#CBD5E1`.
- **Ghost / Tertiary**: Transparent background, text `#475569`, hover text `#0F172A` with `#F1F5F9` background.

### Input Fields & Search Bars
- Standard height: 40px (Desktop), 44px (Mobile).
- Background `#FFFFFF`, 1px border `#E2E8F0`. 
- Active Focus: 1px `#4F46E5` border with `0 0 0 3px rgba(79, 70, 229, 0.15)` focus ring.
- Global AI Talent Command Bar: Enlarged 48px height, subtle inset shadow, left-aligned search icon with violet sparkle badge, and `Cmd + K` keyboard shortcut pill.

### AI Match Pills & Badges
- **High Match (90-100%)**: Pill container with cyan-violet sheen, background `rgba(6, 182, 212, 0.10)`, text `#0891B2`, border `1px solid rgba(6, 182, 212, 0.25)`. Includes an animated radial indicator dot.
- **Moderate Match (75-89%)**: Background `rgba(99, 102, 241, 0.10)`, text `#4F46E5`, border `1px solid rgba(99, 102, 241, 0.25)`.
- **Standard Badges**: Solid `#F1F5F9` pill, text `#475569`, zero border.

### Candidate Cards & Panels
- Constructed with 12px-16px radius, pure `#FFFFFF` background, and `1px solid #E2E8F0`.
- Top header showcases candidate avatar, verification checkmark, current role, and the top-right docked Match Score component.
- Interactive hover transitions the subtle border color to `#8B5CF6` at 40% opacity while lifting the card by 2px.

### Data Tables
- Header: Sticky `#F8FAFC`, uppercase `11px` bold text with `#64748B`, height 36px, `border-b: 1px solid #E2E8F0`.
- Rows: Alternating white background with seamless border dividers (`#F1F5F9`), cursor pointer, and hover highlight `#F8FAFC`.
- Checkboxes: 16px square, 4px rounded, `#4F46E5` fill when selected with a bold white check indicator.

### Match Score Radial Vector (Specialized Component)
- Compact dual-concentric SVG circular ring rendering the percentage metric. 
- Track filled with `#F1F5F9`; progress stroke uses a gradient stroke transitioning from `#4F46E5` to `#06B6D4` with round line-caps.
